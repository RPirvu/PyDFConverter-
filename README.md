Image to PDF Converter (GUI)

A simple, privacy-first Python app that lets you select multiple images and convert them into a single PDF — **without uploading anything online**.

> I never liked the idea of uploading my personal files to a web service just to convert them to PDF — so I made this.


Features:
 - Select multiple images (JPEG, PNG, BMP, GIF, etc.)
 - Remove selected items or clear the entire list
 - Convert all selected images into a single PDF
 - Simple UI using customtkinter

Built With:
 - Python 3
 - customtkinter - for a simple UI
 - Pillow - for image processing
 - CTkListbox - for list handling

Getting Started:
Install the required libraries: `pip install customtkinter pillow CTkListbox`

Run the application: `python app.py`
